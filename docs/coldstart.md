# Cold start

Generated by `make coldstart` (`scripts/coldstart.sh`). **Local run:** the app image in a container limited to 0.1 CPU and 512 MB (Docker CFS quota) on a laptop, against an already migrated PostgreSQL 18 with no demo seeding. A hosting provider's 0.1 CPU is different hardware, so treat these as relative numbers.

- Date: 2026-10-05
- Machine: Apple M1 Pro, 16 GiB RAM, macOS 26.4; Docker VM: 8 CPUs, 15.6 GiB
- JVM flags in every run: `-XX:MaxRAMPercentage=70 -XX:+UseSerialGC -Xss512k` (as in deploy/render.yaml), plus the variant's flags. The image always ships the AOT cache; `-XX:AOTMode=off` disables it.
- Ready = from `docker run` until `/actuator/health/readiness` is UP. Spring = the "Started MarketDataApplication in N seconds" log line.
