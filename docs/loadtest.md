# Load test

Generated by `make loadtest` (`scripts/loadtest.sh`, `loadtest/k6.js`). **Local run on synthetic data:** k6 and the docker compose stack ran on the same laptop, so these numbers describe this machine, not a deployment.

- Date: 2026-10-05
- Machine: Apple M1 Pro, 16 GiB RAM, macOS 26.4; Docker VM: 8 CPUs, 15.6 GiB
- Containers: app limited to 2 CPUs / 1 GB (Temurin 25 JRE, `-XX:MaxRAMPercentage=75`, virtual threads, Hikari pool 10); PostgreSQL 18.6 limited to 2 CPUs / 2 GB, default settings
- Dataset: 500 synthetic symbols, 1,304,500 daily bars (bars heap 126 MB), generated by the demo seeder
- Client: k6 v2.3.0, requests with `Accept-Encoding: gzip`; per-IP rate limiting disabled (`RATE_LIMIT_ENABLED=false`) because every request comes from one IP
- Mix per request: 40% `/v1/bars/{ticker}` (1 year, up to 1000 rows), 30% `/v1/indicators/{ticker}` (1 year), 20% `/v1/levels/{ticker}`, 10% `/v1/symbols?q=` (prefix search); random ticker each time
- A 20 s warm-up at 100 requests/s runs first and is not reported
